# 3D Asset List for 2D-to-3D Conversion

Free, open-licensed 3D assets organized by game element. All assets listed here are compatible with Godot 4.6 (.glb, .gltf, .obj, .fbx).

---

## 1. FPS Arms & Weapons

### Kenney - Blaster Kit (RECOMMENDED - Primary Weapons)
- **URL:** https://kenney.nl/assets/blaster-kit
- **License:** CC0 (public domain, no attribution required)
- **Contents:** 40 assets including multiple sci-fi blasters, crates, silencers, throwables, smoke effects. All models share a single optimized texture. Scopes and magazines are removable for mix-and-match. Includes animated crates and throwables.
- **Formats:** FBX, OBJ, GLTF
- **Use for:** Player weapons (blasters for the co-op shooter). These are third-person weapon models but work great as world models and can be attached to FPS arms.

### Kenney - Starter Kit FPS (RECOMMENDED - FPS Template)
- **URL:** https://github.com/KenneyNL/Starter-Kit-FPS
- **License:** CC0 (assets), MIT (source code)
- **Contents:** Complete Godot 4.3 FPS template with character controller, weapons, weapon switching, enemies, sprites, and 3D models. Includes first-person weapon viewmodels.
- **Formats:** Native Godot project with GLTF models
- **Use for:** Reference FPS controller, first-person weapon viewmodels, and as a starting point for the FPS conversion. Can extract the arm/weapon models directly.

### PSX Assets - First Person Arms (Stylized FPS Arms)
- **URL:** https://rbgr.itch.io/psx-assets-first-person-arms
- **License:** Check itch.io page (free download)
- **Contents:** Animated low-poly first-person arms. Thumb and index fingers individually moveable. Retro PSX aesthetic.
- **Formats:** FBX, GLTF (GLTF recommended for Godot)
- **Use for:** First-person arm models if you want a retro/stylized look.

### Poly Pizza - Rigged FPS Arms
- **URL:** https://poly.pizza/m/AMGNKfQqVc
- **License:** CC0
- **Contents:** Rigged first-person arms optimized for game engines including Godot.
- **Formats:** GLTF
- **Use for:** Alternative FPS arms with rigging ready for custom animations.

### Sketchfab - Low Poly FPS Arms (Rigged + Animated)
- **URL:** https://sketchfab.com/3d-models/low-poly-fps-arms-rigged-animated-6e6b0613f06a4ab78b89e52095d5d338
- **License:** CC Attribution (check model page)
- **Contents:** Low-poly FPS arms with rig and multiple adjustment widgets for positioning.
- **Formats:** GLTF (downloadable from Sketchfab)
- **Use for:** FPS arms with pre-built animation rig.

## 4. Projectiles

### Kenney - Blaster Kit (Included Projectiles)
- **URL:** https://kenney.nl/assets/blaster-kit
- **License:** CC0
- **Contents:** Includes bullets/projectile models alongside the blasters. Also includes throwables.
- **Use for:** Energy bolt projectiles for player weapons.

### OpenGameArt - Laser Bullets Pack 2020
- **URL:** https://opengameart.org/content/assets-free-laser-bullets-pack-2020
- **License:** Check page (free download)
- **Contents:** Laser bullet sprites/textures with transparency, 32-bit color depth.
- **Use for:** Laser bolt textures for projectile sprites or billboard particles.

### Sketchfab - Animated Low Poly Explosion
- **URL:** https://sketchfab.com/3d-models/animated-low-poly-explosion-15f9fa01e7ae4e5b8f188300ed89c8ea
- **License:** CC Attribution (check model page)
- **Contents:** Animated low-poly explosion mesh.
- **Use for:** Projectile impact effects, enemy death explosions.

**Note:** For projectiles in a 3D FPS, simple geometric meshes (spheres, capsules) with emissive materials + particle trails are often more effective than pre-made models. Godot's GPUParticles3D system can create excellent energy bolts procedurally.

## 6. Effects (Explosions, Muzzle Flashes, Healing)

### Kenney - Particle Pack (RECOMMENDED - Particle Textures)
- **URL:** https://kenney.nl/assets/particle-pack
- **License:** CC0 (public domain)
- **Contents:** 80+ sprites for particles, light cookies, and shaders. Includes fire, smoke, magic, hearts, sparks, and electricity effects.
- **Formats:** PNG sprites
- **Use for:** Billboard particle textures for Godot's GPUParticles3D: muzzle flashes, explosions, healing sparkles, energy effects. These are 2D sprites used as textures on 3D particle emitters.
- **Godot Integration:** Already packaged for Godot at https://godotengine.org/asset-library/asset/783

### Kenney - Smoke Particles
- **URL:** https://kenney.nl/assets/smoke-particles
- **License:** CC0 (public domain)
- **Contents:** Smoke particle sprites in various styles.
- **Formats:** PNG sprites
- **Use for:** Smoke trails, explosion aftereffects, ability visual effects.

### Sketchfab - Machine Gun Muzzle Flash Effect
- **URL:** https://sketchfab.com/3d-models/machine-gun-muzzle-flash-test-effect-b96c7578853a4fa98c7893aa8f777636
- **License:** CC Attribution
- **Contents:** Muzzle flash 3D mesh effect (only 38 triangles).
- **Formats:** GLTF
- **Use for:** Attach to weapon barrel for muzzle flash visual. Extremely lightweight.

### itch.io - EffectBlocks (Godot 3D VFX Pack)
- **URL:** https://bukkbeek.itch.io/effectblocks
- **License:** Check page (has free and paid tiers)
- **Contents:** 60+ particle effects for Godot including fire, explosions, magic, muzzle flashes, impacts, and decals.
- **Formats:** Native Godot scenes
- **Use for:** Drop-in Godot particle effects for all combat visuals. Specifically designed for Godot which saves significant setup time.

**Note:** For healing effects, shield bubbles, and energy auras, Godot's built-in shader system + GPUParticles3D is often the best approach. Use the Kenney Particle Pack textures with custom shaders for healing pulses, shield domes, and scan effects.

## Enemy-to-Asset Mapping

| Game Enemy | Recommended Asset Source | Notes |
|---|---|---|
| **Merge Conflict** (small swarm) | Quaternius LowPoly Robot (scaled down) OR Sci-Fi Essentials robots | Duplicate at small scale, use run + attack anims |
| **Hallucination** (disguise) | Kenney Animated Characters 3 (survivor) OR Ultimate Monsters | Needs "reveal" effect via shader swap |
| **Context Rot** (ranged) | Quaternius Sci-Fi Essentials (robot enemy) | Use ranged attack animation |
| **Dependency Hell** (tank) | Quaternius Ultimate Space Kit (mech) OR Ultimate Monsters (large) | Pick bulkiest model, scale up |
| **Kernel Panic** (boss) | Quaternius Ultimate Monsters (largest creature) | Scale up significantly, add custom VFX |

## Format Compatibility with Godot 4.6

All recommended assets are available in at least one Godot-compatible format:
- **GLTF/GLB** (preferred for Godot - best import support)
- **FBX** (supported via ufbx importer in Godot 4.x)
- **OBJ** (supported, no animations)
- **Blend** (supported if Blender is installed, full feature import)
